Privacy Policy

ORIAN — personal desktop application · Last updated: 2026-10-08

ORIAN is a personal, locally-run desktop application. This policy describes how it handles data.

1. Data Storage

All application data — chat history, notes, credentials and files — remains local on your own computer. ORIAN does not upload personal data to any ORIAN-operated server.

2. Third-Party Services

ORIAN connects to user-authorized third-party services (Google/Gmail, YouTube, trading broker MT5, ad networks) only with the user's explicit consent via OAuth or API keys. Data sent to these services is limited to what the user requests (e.g. reading email, or sending an email the user asked for).

3. LLM Providers

Prompts may be sent to configured AI providers (OpenRouter, Z.ai, Groq, Ollama local) for generating responses. Local models (Ollama) process data entirely on-device.

4. Email Access

Gmail access is read/send scoped, used only to show the user their inbox and to send emails the user explicitly requests. Tokens are stored encrypted locally (Electron safeStorage).

5. No Selling of Data

Personal data is never sold, shared for advertising, or transferred to third parties beyond the services the user explicitly connects.

6. Contact

For questions about this policy, contact the developer at ankit6789565@gmail.com.
